Torrent Desk

A small, fast Windows app that searches several torrent sources at once and downloads with its own built-in engine. No other torrent program needed, no ads, no account.

Download for Windows v0.1.1 · 6 MB

Windows 10 and 11, 64-bit · installs for your user only, no admin rights · about 40 MB of memory

Features

Everything is in one window with three tabs: Search, Downloads and Settings.

Search many sources at once

  • One search box asks every switched-on source at the same time and merges duplicates into one list.
  • Filters: category (video, audio, apps, games, other), trusted uploaders only and hide 0 seeders.
  • Sort by size, seeders or leechers. Click a name for details and the file list.
  • The status line shows how many results each source gave. An empty search shows The Pirate Bay top 100.
  • Adult results are hidden unless you turn them on.

Built-in download engine

  • Downloads with its own engine. You don't need qBittorrent, uTorrent or any other client.
  • Progress, speed, peers and time left for each download.
  • Pause and resume, even after closing the app: downloads continue where they stopped.
  • Pick files: untick the parts of a torrent you don't want.
  • Open the folder or a finished file, or remove a download, with or without its files.

Play while it downloads

Start watching a video or listening to music before the download finishes. The built-in player works best with MP4 and WebM. It only runs on your own computer, so no other program or website can read from it.

Magnet links and .torrent files

  • Paste any magnet link, use Open .torrent…, or drag a .torrent file onto the window.
  • Optionally let Windows open magnet links and .torrent files with Torrent Desk. Only one copy runs, so a clicked link goes straight to the open window.
  • Copy link copies a result's magnet link to share it.

Download queue

Set how many downloads run at once (3 by default). The rest wait as queued and start by themselves, oldest first. Start now lets one skip the line.

Runs quietly in the tray

Closing the window keeps downloads going in the system tray, which shows the current speeds. A Windows notification tells you when a download finishes. You can switch both off.

Settings

  • Download folder (default Downloads\Torrent Desk).
  • Upload and download speed limits, applied at once.
  • Keep seeding after a download finishes, or stop sharing as soon as your files are complete (the default).
  • Which search sources to use.

Keeps search working

Torrent sources change and go down without warning. Torrent Desk checks every source on start-up and after a failed search. If one stops answering, a banner names it instead of showing an empty list, and Check again retries. You can add other addresses for The Pirate Bay in Settings. The app never downloads code, only search results.

Search engines used

Torrent Desk does not host any torrents. It asks these public search services and shows their results together.

Knaben

Main source · on

A meta-search engine (knaben.org) that searches many torrent sites at once, including The Pirate Bay, 1337x, Nyaa, YTS and more. Gives the widest results.

The Pirate Bay

On

Asked directly through its public API (apibay.org). Adds uploader badges (trusted, VIP) and full file lists, and supplies the top 100 shown when the search box is empty. Other addresses can be added in Settings if it moves.

torrents-csv

Optional · off by default

An open database of torrents (torrents-csv.com). Switch it on in Settings for extra results.

Please download responsibly. While a torrent downloads, it also uploads pieces to other people. Sharing copyrighted material without permission is illegal in most countries. Use Torrent Desk for content you have the right to download, such as Linux distributions, public-domain films and music, and openly licensed software.
